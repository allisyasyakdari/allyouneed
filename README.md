# 🐱 MimiStore - Web Reseller APK & Akun Premium 🐾

Website landing page interaktif dengan tema **pink muda pastel dan elemen kucing lucu**, didesain khusus untuk reseller APK / Akun Premium agar pembeli dapat dengan mudah melihat katalog produk, mengecek bukti transaksi, menyalin rekening pembayaran, dan langsung order via WhatsApp dengan format chat otomatis.

Dibuat tanpa ketergantungan framework yang rumit (*zero build tools*), sehingga **100% langsung siap di-hosting secara gratis di GitHub Pages**.

---

## ✨ Fitur Unggulan

- 🎨 **Tema Pink Pastel & Ornamen Kucing**: Aksen telinga kucing, floating paws, animasi wiggle maskot, dan tipografi manis yang tetap sangat nyaman dan jelas dibaca.
- 🔍 **Katalog Interaktif**:
  - Filter kategori instan (Streaming, Musik, Desain/Editing, AI & Tools, VPN).
  - Fitur pencarian *live search* tanpa reload.
  - Kartu produk informatif: Label harga normal & promo, badge terlaris, durasi, dan rincian fitur.
- 💬 **Direct WhatsApp Generator**:
  - Tombol *"Order via WA"* langsung menyusun pesan otomatis yang menyebutkan nama produk, durasi paket, dan nominal harga siap kirim ke admin.
- 🛡️ **Bukti Transaksi & Testimoni (Proof)**:
  - Galeri screenshot bukti transfer dan chat kepuasan pembeli.
  - Fitur *Lightbox Zoom* (klik gambar untuk memperbesar secara penuh).
- 💳 **Metode Pembayaran Lengkap dengan Fitur Salin**:
  - Dukungan QRIS, DANA, GoPay, ShopeePay, BCA, Seabank dengan tombol 1-klik untuk menyalin nomor rekening + notifikasi toast imut.
- ❓ **FAQ Akordion & Garansi**: Menjelaskan ketentuan akun (privat vs sharing) dan tata cara klaim garansi.
- 📱 **100% Responsif & Mobile-Friendly**: Tampilan sempurna di semua ukuran layar smartphone dan laptop.

## 🚀 Cara Menjalankan Secara Lokal

1. Anda cukup klik ganda (double-click) file `index.html`, atau buka melalui browser (Google Chrome, Microsoft Edge, dll).
2. Bila menggunakan Laragon, pastikan server Apache aktif, lalu buka `http://localhost/allyouneed` atau `http://allyouneed.test` di browser.

## 🌐 Cara Hosting Gratis di GitHub Pages

Baca panduan lengkap langkah demi langkah pada file [TUTORIAL_HOSTING_GITHUB.md](./TUTORIAL_HOSTING_GITHUB.md).
Hanya butuh 3 menit, tanpa perlu membeli domain ataupun sewa hosting berbayar!
